# Game Save Convert v3.0

Утилита для конвертации сохранений Resident Evil 9 Requiem между Steam и crack (Goldberg/GSE) версиями. Автоматически определяет, расшифровывает и перешифровывает сейвы под ваш текущий Steam ID.

## Возможности

- **Steam <-> Crack** — перенос сохранений в обе стороны
- **Автодетекция платформы** — по пути к папке сохранений (Steam/GSE)
- **Даунгрейд BUILD** — автоматический патч версии сейвов при переносе Steam→Crack
- **remotecache.vdf** — автоматическая генерация для Steam (синхронизация облака)
- **Обработка data00-1.bin** — патч version counter для сохранения игровых настроек

## Как это работает

RE9 шифрует файлы сохранений с привязкой к Steam ID. При переносе из другого источника сейвы становятся нечитаемыми.

Утилита автоматически:
1. Проверяет, подходят ли сейвы к вашему аккаунту
2. Если нет — определяет исходный Steam ID по базе известных ID (мгновенно)
3. Если не найден — полный перебор (~4 мин, выполняется один раз)
4. Проверяет BUILD версию всех файлов (блокирует неподдерживаемые)
5. Перешифровывает сохранения во временной папке
6. При переносе на crack — даунгрейдит BUILD и патчит version counter
7. Создаёт резервную копию оригинальных файлов
8. Копирует перешифрованные файлы в папку сохранений
9. При переносе на Steam — генерирует `remotecache.vdf`

Оригинальные файлы никогда не модифицируются напрямую — вся работа происходит во временной папке.

## Установка

1. Скачайте `installer.exe` со страницы [Releases](../../releases/latest)
2. Запустите от имени администратора
3. Подтвердите согласие на передачу Steam ID (см. раздел ниже)
4. Нажмите «Установить»

Установщик автоматически:
- Скачает профиль шифрования RE9
- Установит .NET 10 Desktop Runtime (если не установлен)
- Скачает и распакует `save-convert.exe` с зависимостями
- Добавит утилиту в системный PATH
- Скачает инструкцию (README.md) локально

**После установки ОБЯЗАТЕЛЬНО перезагрузите компьютер**, чтобы системный PATH обновился. Без перезагрузки `save-convert.exe` не будет найден в командной строке.

### Передача Steam ID

**При первом запуске утилиты ваш Steam ID автоматически отправляется в базу данных.**

Это необходимо для:
- Ускорения будущих конвертаций (ваш ID добавляется в список известных)
- Без добавления в базу расшифровка и шифрование сохранений **невозможны**

Передаётся только числовой Steam ID и код игры. Никакие другие данные не собираются.

## !! ВАЖНО: отключите Steam Cloud перед конвертацией

**При переносе сохранений на Steam ОБЯЗАТЕЛЬНО отключите облачную синхронизацию для RE9:**

1. Откройте Steam → Библиотека → ПКМ по Resident Evil 9 → Свойства
2. Вкладка «Общие» → снимите галочку **«Сохранять игры в Steam Cloud»**
3. Запустите конвертацию
4. Запустите игру, убедитесь что сейвы загрузились
5. После этого можете включить синхронизацию обратно

**Без этого Steam перезапишет сконвертированные файлы облачной копией и сейвы не загрузятся!**

## Использование

### Конвертация сохранений

```
save-convert.exe -<steam_id> -<путь_к_папке_сохранений> -re9 [-silent] [-crack|-steam]
```

### Проверка Steam ID

```
save-convert.exe check <steam_id>
```

Проверяет, есть ли ваш Steam ID в базе. Если нет — автоматически отправляет заявку на добавление. ID будет добавлен в течение дня.

### Параметры

| Параметр | Описание |
|----------|----------|
| `steam_id` | Ваш Steam ID (числовой) |
| `путь` | Полный путь к папке с файлами сохранений (`.bin`) |
| `-re9` | Код игры (Resident Evil 9 Requiem) |
| `-silent` | Без окон и диалогов (для автоматизации) |
| `-crack` | Принудительно задать целевую платформу — crack |
| `-steam` | Принудительно задать целевую платформу — Steam |

Все параметры (кроме `-silent`, `-crack`, `-steam`) обязательны. Порядок не важен, но каждый должен начинаться с `-`.

### Примеры

**Crack → Steam** (перенос сохранений из crack на Steam):
```
save-convert.exe -821127145 -"C:\Program Files (x86)\Steam\userdata\821127145\3764200\remote\win64_save" -re9
```

**Steam → Crack** (перенос сохранений со Steam на crack):
```
save-convert.exe -76561197960287930 -"C:\Users\User\AppData\Roaming\GSE Saves\3764200\remote\win64_save" -re9
```

Тихий режим (без окон):
```
save-convert.exe -821127145 -"C:\Program Files (x86)\Steam\userdata\821127145\3764200\remote\win64_save" -re9 -silent
```

Принудительная платформа (если автодетекция не работает):
```
save-convert.exe -821127145 -"D:\MySaves\win64_save" -re9 -steam
```

Проверка Steam ID:
```
save-convert.exe check 76561197960287930
```

### Автоматический запуск через Steam

Можно настроить автоматическую конвертацию при каждом запуске RE9 через Steam.

**Steam → Библиотека → ПКМ по RE9 → Свойства → Параметры запуска:**

```
cmd /c start /wait "" "C:\Tools\SaveCompat\save-convert.exe" -ВАШ_STEAM_ID -"C:\Program Files (x86)\Steam\userdata\ВАШ_STEAM32\3764200\remote\win64_save" -re9 -silent & start "" %command%
```

Пример для Steam ID 821127145:
```
cmd /c start /wait "" "C:\Tools\SaveCompat\save-convert.exe" -821127145 -"C:\Program Files (x86)\Steam\userdata\821127145\3764200\remote\win64_save" -re9 -silent & start "" %command%
```

Конвертер проверит сейвы, при необходимости перешифрует, затем запустит игру. Если сейвы уже совместимы — игра запустится мгновенно.

### Где взять Steam ID

Ваш Steam ID — это числовой идентификатор аккаунта. Его можно найти:
- На странице профиля Steam (URL содержит ID)
- В настройках эмулятора (Goldberg, GreenLuma и др.)
- В конфигах кряка (например, `ColdClientLoader.ini` → параметр `AccountId`)

## Даунгрейд BUILD

При переносе сохранений со Steam на crack, BUILD версия файлов автоматически понижается с `0x01001002` (Steam) до `0x01001000` (crack). Это необходимо, потому что старая версия игры (crack) не может загрузить сейвы с новым BUILD.

Даунгрейд затрагивает:
- Все файлы `data000.bin`, `*Slot*.bin` — BUILD по смещению 0x5C
- `data00-1.bin` — BUILD по смещению 0x4C + патч version counter (смещение 0x28)

Version counter в `data00-1.bin` увеличивается на +2, чтобы игра приняла файл настроек (иначе сбрасывает на дефолтные).

## remotecache.vdf

При переносе на Steam автоматически генерируется файл `remotecache.vdf` рядом с сохранениями. Он нужен для того, чтобы Steam Cloud Sync распознал файлы и не перезаписал их облачной версией.

## Коды возврата

| Код | Значение | Что делать |
|-----|----------|------------|
| 0 | Сейвы уже совместимы или успешно сконвертированы | Ничего, всё ОК |
| 1 | Ошибка (нет интернета, отмена, сбой, неподдерживаемая версия) | Проверьте лог `C:\Tools\SaveCompat\save-convert.log` |
| 2 | Исходный Steam ID сохранений не найден | Полный перебор не дал результатов |
| 3 | Ваш Steam ID отсутствует в базе | Запустите `save-convert check <ваш_id>` |

## Резервные копии

Перед каждой конвертацией автоматически создаётся бэкап оригинальных файлов:

```
<папка_сохранений>/
├── data000.bin                    # Текущие (сконвертированные) сейвы
├── data00-1.bin
├── backup_<src>_<dst>_<дата>/     # Бэкап
│   ├── info.txt                   # Детали конвертации
│   ├── data000.bin                # Оригинальные файлы
│   └── data00-1.bin
```

- Хранятся **3 последних** бэкапа, старые удаляются автоматически
- Для восстановления: скопируйте `.bin` файлы из бэкапа обратно в папку сохранений

## Безопасность данных

- Оригинальные файлы **никогда** не модифицируются напрямую
- Перешифровка выполняется во временной папке
- Только после успешной перешифровки ВСЕХ файлов создаётся бэкап и копируются результаты
- При любой ошибке оригиналы остаются нетронутыми

## Защита Steam ID

Утилита работает **только** с ID из авторизованного списка. Это двусторонняя защита:

- **Расшифровка**: если исходный Steam ID сохранений отсутствует в списке — будет запущен полный перебор (~4 мин)
- **Шифрование**: если ваш целевой Steam ID отсутствует в списке — зашифровать под него нельзя

При первом запуске найденный исходный ID автоматически отправляется в базу для ускорения будущих конвертаций у других пользователей.

## Устранение неполадок

### «Profiles directory not found» (код 1)
Установка не завершена или повреждена. Запустите `installer.exe` повторно.

### «Не удалось загрузить базу Steam ID» (код 1)
Нет подключения к интернету. Утилите необходим интернет для загрузки списка авторизованных ID.

### «Сохранения несовместимы» — исходный ID не найден (код 2)
Полный перебор не дал результатов. Это крайне редкая ситуация — обратитесь к разработчику.

### «Ваш аккаунт не найден» (код 3)
Ваш Steam ID отсутствует в базе. Запустите `save-convert check <ваш_steam_id>` для отправки заявки на добавление.

### «Файл создан на неподдерживаемой версии» (код 1)
Сохранения созданы на более новой версии игры, чем поддерживает текущая версия save-convert. Скачайте обновлённую версию утилиты.

### Сейвы не загружаются после конвертации
1. Убедитесь, что указали `-re9`
2. Проверьте путь к сохранениям — он должен вести к папке с `.bin` файлами
3. Попробуйте восстановить из бэкапа и запустить конвертацию снова

## Известные проблемы

### Для работы со Steam версиями на вашем аккаунте должны быть хоть какие-то сохранения.
Дойдите до первого чекпоинта и все сохранения будут работать.

### Сейвы разных версий несовместимы! *Требует проверки*

### Разная шифровка файлов сохранений.
Крайне редкая ситуация, когда сейвы уже испорчены.
Игрок зашёл в игру без конвертера, сейвы не подхватились и пересоздался основной файл data00-1.bin с целевым Steamid. Остальные файлы сохранений остались зашифрованы исходным SteamId.
*Решение*
Вручную перешифровывать файлы по отдельности (требуется помощь мерча, восстановление возможно)
Планируется добавление функции ремонта сейвов в v3

### Лог-файл
Подробный лог каждого запуска сохраняется в:
```
C:\Tools\SaveCompat\save-convert.log
```
