# Game Save Convert v5.0

[English version](README_EN.md)

Универсальный конвертер сохранений RE Engine игр между Steam и crack (Goldberg/GSE) версиями. Автоматически определяет игру по AppID, расшифровывает и перешифровывает сейвы под ваш текущий Steam ID.

## Поддерживаемые игры

| Игра | Код | AppID |
|------|-----|-------|
| Resident Evil 9 Requiem | `re9`, `requiem` | 3764200 |
| Dragon's Dogma 2 | `dd2`, `dogma2` | 2054970 |
| Monster Hunter Wilds | `mhw`, `wilds` | 2246340 |
| Monster Hunter Stories 3 | `mhs3`, `stories3` | 2852190 |
| Dead Rising Deluxe Remaster | `dr`, `deadrising` | 2527390 |
| Kunitsu-Gami | `kg`, `kunitsu` | 2510710 |
| PRAGMATA | `pragmata` | 3357650 |
| Mega Man Star Force | `mmsf`, `megaman`, `starforce` | 3500390 |

## Возможности

- **Универсальный** — поддержка всех RE Engine игр с MandarinJuice профилями
- **Авто-детекция игры** — определение по AppID из пути к сохранениям (параметр `-game` опционален)
- **Steam <-> Crack** — перенос сохранений в обе стороны
- **Автодетекция платформы** — по пути к папке сохранений (Steam/GSE)
- **Автоматический даунгрейд BUILD** — для RE9: если сейв новее целевой версии, BUILD автоматически понижается
- **Быстрый brute-force** — определение исходного ID за 5-17 секунд
- **Offline-first** — работает без интернета, список ID используется только как ускоритель
- **remotecache.vdf** — автоматическая генерация для Steam (с защитой от перезаписи)
- **Без ограничений** — не требует одобрения, whitelist или передачи данных

## Что нового в v5.0

- **Универсальный конвертер**: поддержка всех 8 RE Engine игр вместо только RE9
- **Авто-детекция игры**: AppID автоматически определяется из пути к сохранениям — параметр `-game` стал опциональным
- **Расширенные алиасы**: `re9`, `dd2`, `mhw`, `mhs3`, `dr`, `kg`, `pragmata`, `mmsf`
- **Умный BUILD patching**: даунгрейд BUILD автоматически применяется только для RE9; для других игр — только re-sign
- **Silent mode graceful**: при неизвестном BUILD в silent mode — re-sign без ошибки вместо отказа
- **pre-launch-steam.cmd**: поддержка всех 8 игр + авто-детекция через `%SteamAppId%`
- **Installer**: URL профилей обновлён на latest — всегда актуальные профили

## Как это работает

RE Engine игры шифруют файлы сохранений с привязкой к Steam ID. При переносе из другого источника сейвы становятся нечитаемыми.

Утилита автоматически:
1. Определяет игру по AppID из пути (или по параметру `-game`)
2. Проверяет, подходят ли сейвы к вашему аккаунту
3. Если нет — пытается скачать список известных ID (1 сек)
4. Если скачан — мгновенный поиск по списку
5. Если не скачан или не найден — полный перебор (~5-17 сек, выполняется один раз)
6. Перешифровывает сохранения во временной папке
7. Для RE9: автоматически даунгрейдит BUILD если файл новее целевого
8. Создаёт резервную копию оригинальных файлов
9. Копирует перешифрованные файлы в папку сохранений
10. При переносе на Steam — генерирует `remotecache.vdf` (read-only)

Оригинальные файлы никогда не модифицируются напрямую — вся работа происходит во временной папке.

## Установка

1. Скачайте `installer.exe` со страницы [Releases](../../releases/latest)
2. Запустите от имени администратора
3. Нажмите "Установить"

Установщик автоматически:
- Скачает профили шифрования для всех поддерживаемых игр
- Установит .NET 10 Desktop Runtime (если не установлен)
- Скачает и распакует `save-convert.exe` с зависимостями
- Добавит утилиту в системный PATH
- Скачает инструкцию (README.md) локально

**После установки ОБЯЗАТЕЛЬНО перезагрузите компьютер**, чтобы системный PATH обновился. Без перезагрузки `save-convert.exe` не будет найден в командной строке.

### Структура после установки

```
C:\Tools\SaveCompat\
├── save-convert.exe              # Основная утилита
├── save-convert.dll              # Основная библиотека
├── MandarinJuiceCore.dll         # Движок шифрования
├── *.dll                         # Зависимости

├── README.md                     # Эта инструкция
└── mandarin\
    └── _profiles\                # Профили шифрования (все игры)
        ├── Resident Evil 9 Requiem v1.bin
        ├── Dragon's Dogma 2 v1.bin
        ├── Monster Hunter Wilds v1.bin
        └── ...
```

## !! ВАЖНО: отключите Steam Cloud перед конвертацией

**При переносе сохранений на Steam ОБЯЗАТЕЛЬНО отключите облачную синхронизацию для игры:**

1. Откройте Steam -> Библиотека -> ПКМ по игре -> Свойства
2. Вкладка "Общие" -> снимите галочку **"Сохранять игры в Steam Cloud"**
3. Запустите конвертацию
4. Запустите игру, убедитесь что сейвы загрузились
5. После этого можете включить синхронизацию обратно

**Без этого Steam перезапишет сконвертированные файлы облачной копией и сейвы не загрузятся!**

## Использование

### Конвертация сохранений

```
save-convert.exe -<steam_id> -<путь_к_папке_сохранений> [-game] [-silent] [-crack|-steam] [-targetsavebuild <build>]
```

### Бенчмарк

```
save-convert.exe benchmark
```

Тест скорости brute-force: однопоточный и многопоточный, оценка времени полного перебора.

### Параметры

| Параметр | Описание |
|----------|----------|
| `steam_id` | Ваш Steam ID (числовой) — обязателен |
| `путь` | Полный путь к папке с файлами сохранений (`.bin`) — обязателен |
| `-game` | Код игры (опционален — при отсутствии игра определяется по AppID из пути) |
| `-silent` | Без окон и диалогов (для автоматизации) |
| `-crack` | Принудительно задать целевую платформу — crack |
| `-steam` | Принудительно задать целевую платформу — Steam |
| `-targetsavebuild <build>` | Переопределить целевой BUILD для даунгрейда (только RE9). Принимает hex (`0x01001000`) или алиас (`v4`, `v5`, `v6`, `crack`, `steam`). По умолчанию: `0x01001002` |

### Примеры

**RE9: Crack -> Steam** (с авто-детекцией игры по AppID):
```
save-convert.exe -821127145 -"C:\Program Files (x86)\Steam\userdata\821127145\3764200\remote\win64_save"
```

**RE9: с явным указанием игры**:
```
save-convert.exe -821127145 -"C:\Program Files (x86)\Steam\userdata\821127145\3764200\remote\win64_save" -re9
```

**Monster Hunter Wilds**:
```
save-convert.exe -821127145 -"C:\Program Files (x86)\Steam\userdata\821127145\2246340\remote\win64_save" -mhw
```

**Dragon's Dogma 2 (авто-детекция)**:
```
save-convert.exe -821127145 -"C:\Program Files (x86)\Steam\userdata\821127145\2054970\remote\win64_save" -silent
```

**RE9: С переопределением целевого BUILD**:
```
save-convert.exe -76561197960287930 -"C:\Users\User\AppData\Roaming\GSE Saves\3764200\remote\win64_save" -re9 -targetsavebuild v4
```

Тихий режим (без окон):
```
save-convert.exe -821127145 -"C:\Program Files (x86)\Steam\userdata\821127145\3764200\remote\win64_save" -silent
```

### Автоматический запуск через Steam

Можно настроить автоматическую конвертацию при каждом запуске игры через Steam.

#### Вариант 1: через pre-launch-steam.cmd (рекомендуется)

**Steam -> Библиотека -> ПКМ по игре -> Свойства -> Параметры запуска:**

```
"C:\Tools\SaveCompat\pre-launch-steam.cmd" re9 %command%
```

Или без кода игры (авто-детекция через %SteamAppId%):
```
"C:\Tools\SaveCompat\pre-launch-steam.cmd" %command%
```

Коды игр для pre-launch-steam.cmd: `re9`, `mhw`, `dd2`, `dr`, `kg`, `mhs3`, `mmsf`, `pragmata`

#### Вариант 2: прямой вызов

```
cmd /c start /wait "" "C:\Tools\SaveCompat\save-convert.exe" -ВАШ_STEAM_ID -"C:\Program Files (x86)\Steam\userdata\ВАШ_STEAM32\3764200\remote\win64_save" -re9 -silent & start "" %command%
```

### Где взять Steam ID

Ваш Steam ID — это числовой идентификатор аккаунта. Его можно найти:
- На странице профиля Steam (URL содержит ID)
- В настройках эмулятора (Goldberg, GreenLuma и др.)
- В конфигах кряка (например, `ColdClientLoader.ini` -> параметр `AccountId`)

## BUILD Downgrade (только RE9)

Даунгрейд выполняется автоматически при конвертации RE9. Если BUILD файла выше целевого (`0x01001002` по умолчанию), он понижается. Если BUILD файла равен или ниже — ничего не меняется.

Для других игр BUILD patching не выполняется (только re-sign).

| BUILD | Версия | Алиас |
|-------|--------|-------|
| `0x01001000` | v1.0 (initial release) | `v4`, `crack` |
| `0x01001001` | v1.0.1 | — |
| `0x01001002` | v1.1 (April 2026 patch) | `v5`, `steam` |
| `0x01002000` | v2.0 (March 2026 Steam update) | `v6` |

## Коды возврата

| Код | Значение | Что делать |
|-----|----------|------------|
| 0 | Сейвы уже совместимы или успешно сконвертированы | Ничего, всё ОК |
| 1 | Ошибка (отмена, сбой, неподдерживаемая версия) | Проверьте лог `save-convert.log` |
| 2 | Исходный Steam ID сохранений не найден | Полный перебор не дал результатов |

## Резервные копии

Перед каждой конвертацией автоматически создаётся бэкап оригинальных файлов:

```
<папка_сохранений>/
├── data000.bin                    # Текущие (сконвертированные) сейвы
├── data00-1.bin
├── backup_<src>_<dst>_<дата>/     # Бэкап
│   ├── info.txt                   # Детали конвертации
│   ├── data000.bin                # Оригинальные файлы
│   └── data00-1.bin
```

- Хранятся **3 последних** бэкапа, старые удаляются автоматически
- Для восстановления: скопируйте `.bin` файлы из бэкапа обратно в папку сохранений

## Безопасность данных

- Оригинальные файлы **никогда** не модифицируются напрямую
- Перешифровка выполняется во временной папке
- Только после успешной перешифровки ВСЕХ файлов создаётся бэкап и копируются результаты
- При любой ошибке оригиналы остаются нетронутыми
- **Не отправляет никаких данных на сервер** — работает полностью локально

## Устранение неполадок

### "Profiles directory not found" (код 1)
Установка не завершена или повреждена. Запустите `installer.exe` повторно.

### "No matching profile" (код 1)
Профиль для указанной игры отсутствует. Переустановите для обновления профилей.

### "Сохранения несовместимы" — исходный ID не найден (код 2)
Полный перебор не дал результатов. Это крайне редкая ситуация — обратитесь к разработчику.

### Сейвы не загружаются после конвертации
1. Проверьте путь к сохранениям — он должен вести к папке с `.bin` файлами
2. Убедитесь что у вас есть профиль для нужной игры
3. Попробуйте восстановить из бэкапа и запустить конвертацию снова

### Лог-файл
Подробный лог каждого запуска сохраняется рядом с exe:
```
<install_dir>\save-convert.log
```
