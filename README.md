# Game Save Convert

Утилита для конвертации игровых сохранений между разными Steam ID. Автоматически расшифровывает сейвы, подписанные неизвестным Steam ID, и перешифровывает под ваш текущий ID.

## Как это работает

Многие игры шифруют сохранения с использованием Steam ID игрока. Когда сейвы приходят из другого источника (другой ПК, другой кряк/репак), они становятся нечитаемыми из-за несовпадения Steam ID.

Утилита:
1. Определяет исходный Steam ID по одному тестовому файлу
2. Перешифровывает все сейвы под ваш целевой Steam ID
3. Перед изменениями создаёт резервную копию

## Быстрая установка

Запустить в PowerShell (от администратора):

```powershell
irm https://raw.githubusercontent.com/AlexeyGoto/game-save-convert/main/install.ps1 | iex
```

Установщик:
- Скачает и распакует [MandarinJuice](https://github.com/mi5hmash/MandarinJuice) CLI
- Установит .NET 10 runtime при необходимости
- Установит `save-convert.exe` и добавит в PATH

## Использование

```
save-convert.exe -<steam_id> -<путь_к_папке_сохранений> -<игра>
```

### Параметры

| Параметр | Описание |
|----------|----------|
| `steam_id` | Ваш Steam ID |
| `путь` | Путь к папке с сохранениями (.bin файлы) |
| `игра` | Код игры (обязательный) — см. таблицу ниже |

### Коды игр

| Код | Игра |
|-----|------|
| `re9` | Resident Evil 9 Requiem |
| `mhw` | Monster Hunter Wilds |
| `dd2` | Dragon's Dogma 2 |
| `dr` | Dead Rising |
| `kg` | Kunitsu-Gami |

### Пример

```
save-convert.exe -76561197960287930 -"C:\Users\User\AppData\Roaming\GSE Saves\3764200\remote\win64_save" -re9
```

### Коды возврата

| Код | Значение |
|-----|----------|
| 0 | Сейвы совместимы или успешно сконвертированы |
| 1 | Ошибка (нет инструментов, сети, неверные аргументы) |
| 2 | Исходный Steam ID не найден в списке известных |
| 3 | Ваш Steam ID отсутствует в авторизованном списке |

### Резервные копии

Перед конвертацией создаётся бэкап в папке сохранений:

```
backup_<исходный_id>_<целевой_id>_<дата_время>/
├── info.txt          # Детали конвертации
├── data00-1.bin      # Оригинальные файлы сохранений
└── ...
```

Хранятся только 3 последних бэкапа, старые удаляются автоматически.

## Защита Steam ID

Утилита работает только с ID, которые есть в авторизованном списке (`steam_ids.txt`). Это **двусторонняя защита**:

- **Расшифровка**: если исходный Steam ID сохранений не найден в списке — расшифровать их нельзя
- **Шифрование**: если ваш целевой Steam ID отсутствует в списке — зашифровать сохранения под него тоже нельзя

Это сделано для предотвращения манипуляций с блокировкой чужих сейвов. Без вашего ID в списке невозможно ни прочитать, ни перезаписать сохранения.

## Добавление Steam ID

Если вашего Steam ID нет в списке и утилита отказывает в работе — [создайте Issue](../../issues/new) с вашим Steam ID. Мы добавим его в базу.
